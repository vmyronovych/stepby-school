# Структура курсів

Курс — модуль із власними джерелами, матеріалами, стилями, перевірками й правилами для AI. Першим перенесено `src/courses/robotics`; інші курси залишаються у чинній структурі до окремої міграції.

## Власність

```text
src/courses/robotics/
  CLAUDE.md                       правила курсу й навігатор для AI
  .agents/skills/                  процедури підготовки заняття та схем
  course.ts                       каталог і порядок занять
  index.ts                        публічний каталог і посилання
  ui.ts                           публічні React-екрани
  circuit.ts                      публічний двигун для композиції
  documents.ts                    збережені документи
  publication.cjs                 опис публікації матеріалів
  lessons/
    lesson-01/
      metadata.ts                 назва й опис картки
      lesson.ts                   навчальний зміст
      assets/                     унікальні зображення
    lesson-07/
      experiment.ts               готове коло для вбудованого досліду
      files/                      редаговані проєкти Mcar
      assets/                     зображення блоків
    lesson-08/
      MotorLesson.tsx             спеціальний UI цього заняття
      lesson08-content.ts         практика й матеріали вчителя
      teacher-notes.md             докладний конспект
      captures.json               походження зображень
      files/
      assets/
  shared/
    content/                      типи, спільна підготовка, каталог зображень
    ui/                           показ, практика, навігація матеріалів
    styles/                       стилі лише цього курсу
    assets/                       ілюстрації для кількох занять
    documents/                    збережені матеріали попереднього курсу
  tools/circuit/                  єдиний двигун, UI та CSS електричного кола
  scripts/                        генератори й перевірки
  docs/                           методика та спільні метадані генерації
  tests/                          перевірки курсу
    browser/                      браузерні сценарії
```

Створюй лише потрібні папки. Файл належить найвужчій області, яка ним користується. Спільну схему кількох занять зберігай у `shared/assets`, а не копіюй між заняттями. Перелік занять і метадані генерації закономірно збираються на рівні курсу.

## Залежності

- Застосунок підключає курс через задокументовані публічні входи. Каталог відділений від UI, щоб читання метаданих не створювало залежності від React-екранів та їхнього життєвого циклу.
- Курс використовує загальні кнопки, типи та навігацію. Ці загальні модулі не імпортують приватні файли курсу.
- Рівень композиції (`app`, каталог, реєстрація runtime і документів) може підключати курси. Він не є бібліотекою спільних примітивів.
- Курси не імпортують одне одного. Заняття не імпортують сусідні заняття. Дані конкретного досліду передаються в спільний UI через props.
- `npm run check:architecture` перевіряє публічні входи, відсутність імпортів між заняттями й циклів TypeScript-модулів. Перевірка також входить до `npm test`.

## Джерела та публікація

Єдине редаговане джерело зображень і `.mcar` — папка курсу. `scripts/build.mjs` читає маніфест `publication.cjs` і копіює матеріали до `dist/assets/robotics/`. Старі публічні адреси збережені для `file://`, GitHub Pages та завантажень. Весь готовий сайт знаходиться в `dist/`, який не комітиться. Кореневий `index.html` є шаблоном; офлайн відкривається `dist/index.html`. Назви вихідних файлів мають бути унікальними в межах публікації курсу; конфлікт зупиняє збірку.

`npm run dev` показує `dist/` і стежить за TypeScript, вихідним HTML, матеріалами та стилями. Генератори оновлюють джерела; після ручного запуску генератора виконай збірку або використовуй запущений dev-сервер.

`css/documents.css` залишається загальним: попередній `robo.css` фактично оформлював документи багатьох курсів. Специфічні правила карток безпеки й Морзе перенесено до курсу. Наявні CSS-класи документів збережені для сумісності.

## Інструкції для AI

Кореневий `CLAUDE.md` містить загальні вимоги та посилання на локальні правила. `AGENTS.md` спрямовує Codex до цього самого джерела, без дублювання тексту. Читання локальних правил і скілів явне: сама наявність вкладеної папки не є гарантією автоматичного завантаження.

Курсовий `CLAUDE.md` визначає обов’язкові вимоги. Скіл описує конкретну процедуру й посилається на правила та наявні скрипти. Докладна методика живе в `docs/`. Локальний `CLAUDE.md` заняття додається лише за потреби в особливих правилах. Загальні скіли додаємо, коли процедура справді використовується різними курсами; порожнього каталогу заради симетрії немає.

Правила ще не перенесених курсів винесені з кореневого файлу до їхніх чинних областей коду. Це не означає, що самі ці курси вже мігровані.

## Перевірка міграції

Збережи зміст, ідентифікатори й URL. Перевір типи, загальні та курсові тести, весь браузерний набір, прямі `file://`-посилання й публікацію ресурсів. Для змінених генераторів перевір їхній реальний запуск; наявність старого згенерованого файла не доводить працездатність нового шляху.

Навчальні зображення, медіа та ліцензії ще не мігрованих курсів зберігаються у `src/features/media-literacy/assets/` та `src/features/web-development/assets/`. Їхня публікація також відбувається у `dist/assets/`. Це переміщення ресурсів, а не повна міграція структури цих курсів. Див. [публікацію сайту](deployment.md).
