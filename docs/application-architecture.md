# Архітектура застосунку

## Призначення папок і файлів

Навчальні матеріали й інструменти кожного курсу зберігаються в `src/courses/`. Спільні елементи, які можуть використовувати різні курси, — у `src/components/`. Код у `src/app/` поєднує їх у сайт: відкриває потрібні сторінки та обробляє дії користувача.

| Папка або файл | Призначення |
|---|---|
| `index.html` | Початкова HTML-сторінка, яка підключає стилі та код застосунку. Під час збірки копіюється до `dist/`. |
| `dist/` | Готовий сайт для відкриття в браузері або публікації. Створюється під час збірки; його файли не додають до Git. |
| `src/main.tsx` | Запускає застосунок і показує його на сторінці. Також надає команди для керування застосунком з іншого коду. |
| `src/app/` | Поєднує курси та спільні компоненти в сайт. Керує відкритою сторінкою, поточним завданням і діями користувача. |
| `src/app/catalog/` | Показує головну сторінку з курсами, уроки за класами та сторінки тем із завданнями. |
| `src/app/composition.ts` | Під час запуску додає інструменти й документи курсів до спільних переліків, щоб застосунок міг їх відкривати. |
| `src/app/course-pages.ts` | Підключає особливі екрани курсів. Курс передає готовий вміст і визначає, чи показувати шапку та навігаційний ланцюжок. |
| `src/app/documents/` | Визначає, який документ або інтерактивний екран курсу відкрити. Підключає до нього навігацію та дії відповідного курсу. |
| `src/app/tools/` | Об’єднує інструменти математичних курсів і підключає потрібні поля введення умов задачі. Самі обчислення, поля та підказки належать курсам. |
| `src/navigation/` | Будує посилання на сторінки й визначає, що відкрити за частиною адреси після `#`. Підтримує також старі посилання. |
| `src/app/catalog/registry.ts` | Перелічує готові курси в тому порядку, у якому вони з’являються на головній. |
| `src/app/catalog/catalog.ts` | Автоматично отримує описи й уроки з переліку курсів. Також знаходить урок за його інструментом. |
| `src/navigation/course-registry.ts` | Збирає налаштування адрес із курсів: шлях до курсу, формат посилань на уроки та переходи зі старих адрес. |
| `src/courses/` | Містить окрему папку для кожного курсу: його уроки, інструменти, стилі, зображення, тести та правила підготовки матеріалів. |
| `src/courses/mathematics/` | Уроки математики, умови задач і код їх покрокового розв’язання: обчислення у стовпчик, дроби, рівняння та інші теми курсу. |
| `src/courses/algebra/` | Уроки алгебри та інструменти для роботи з областю визначення функції, ірраціональними рівняннями, степенями й радіанами. |
| `src/courses/geometry/` | Уроки про вектори, інтерактивні рисунки та покрокові розв’язання задач. |
| `src/courses/robotics/` | Заняття з робототехніки, симулятор електричного кола, схеми й програми для робота. Тут також зберігаються скрипти для створення навчальних матеріалів. |
| `src/courses/media-literacy/` | Уроки медіаграмотності: навчальні історії, діалоги, учнівські вправи, ілюстрації та пояснення для вчителя. |
| `src/courses/informatics/` | Календарно-тематичні плани й конспекти з інформатики, а також навчальні інструменти «Клавіатура» та «Windows». |
| `src/courses/web-development/` | Уроки HTML і CSS, практичні завдання, редактори коду, зразки результатів, зображення, аудіо й відео для вправ. |
| `src/components/` | Спільні елементи інтерфейсу та допоміжні модулі. Кожен має власну папку й отримує потрібні дані від коду, який його використовує. |
| `src/components/notebook/` | Показує розв’язання на аркуші в клітинку: записи, кроки, рух пера й перенесення чисел. Кроки розв’язання готує курс. |
| `src/components/document/` | Показує переданий навчальний документ: оформлює текст і зміст, збільшує ілюстрації та готує матеріал до друку. |
| `src/components/file-export/` | Створює в браузері ZIP-архіви та таблиці XLSX з одним стовпцем для завантаження. Дані й назви файлів передає курс. |
| `src/runtime/` | Надає навчальним інструментам дані про поточну задачу й крок, спільні типи та функції для переходів і повідомлень. |
| `src/components/notebook/rendering/` | Показує формули, кроки рівнянь, числову пряму та стовпчики; керує письмом і польотами записів. |
| `src/runtime/tool.ts` | Надає курсам спосіб визначити інструмент та перевіряє відповідність його моделі й кроку під час показу. |
| `src/app/tools/register.ts` | Перевіряє визначення інструментів і додає їх до переданого каталогу. |
| `src/lib/math/` | Спільні обчислення без браузера: точна робота з дробами, розбір формул, перетворення рівнянь і розрядне додавання. |
| `css/base.css` | Задає загальне оформлення сайту: кольори, шрифти, відступи, шапку й розміщення основного вмісту. |

## Архітектура

Кожен курс надає об’єкт `Course`: `subject` містить його назву й опис, `topics` — повний перелік уроків, матеріалів та карток інструментів. `app/catalog/registry.ts` містить тільки впорядкований масив цих курсів. Щоб додати курс до каталогу, імпортуй його й додай один запис у цей масив.

- `catalog` містить курси, уроки й реєстр інструментів. Довідника класів і користувачів немає. Групи уроків задає `grades`, а `cls` зберігає сумісність адрес. `initializeApplication()` у `src/app/composition.ts` явно передає каталог і 17 визначень до `registerTools(catalog, tools)`, готує алгебраїчні пояснення й реєструє документи. Контролер викликає її перед першим переходом; повторний виклик безпечний. Сам імпорт модулів нічого не реєструє.
- Кожен математичний курс експортує повний перелік інструментів через `runtime/` і перелік форм через `ui/`. `app/tools/` об’єднує ці переліки без залежності від позицій у масивах. Початкові значення, підказки та приклади належать урокам; спільний вибір прикладу — `components/notebook/inputs`.
- `app/documents/` збирає документи та їхні екрани. Курс формує власні навігаційні посилання й вкладки через публічний вхід `ui/`; `app/documents/navigation.ts` підключає ці налаштування або надає загальний шлях «Головна → курс → документ». `DocumentScreen` отримує готову навігацію й передає її спільному переглядачу; він не містить назв курсів або ідентифікаторів їхніх матеріалів. Курс робототехніки надає власні дії й стан КТП; застосунок передає повідомлення та налаштування руху.
- `App.tsx` отримує готові екрани через `app/course-pages.ts`. Робототехніка й медіаграмотність самі визначають оформлення та видимість шапки в режимах уроку. Спільний контракт цих налаштувань — `runtime/course-view.ts`.
- Інтерактивний вміст документів створюють курси через `ui/`. `app/documents/views.tsx` лише вибирає підключену функцію; він не знає внутрішньої розмітки, контролерів або ідентифікаторів уроків.
- Маршрутизатор читає налаштування адрес із `navigation/course-registry.ts`. Їх визначають окремі публічні файли `routing.ts` у курсах; вони містять тільки дані, тому побудова посилань не потребує запуску застосунку чи завантаження уроків.
- Пошук уроку для пояснювального посилання належить `app/catalog/catalog.ts`. Під час запуску застосунок передає його через `runtimeServices.topicForTool`; математичне ядро й зошит не завантажують загальний каталог.
- `runtime/` не імпортує `app` або курси. `app/catalog/CatalogPage.tsx` показує загальний каталог для учнів і вчителів.
- `src/app/controller.ts` керує маршрутом, умовою, моделлю, кроком та історією прокрутки.
- React читає незмінні знімки через `useSyncExternalStore`; публікація кроку синхронна для вимірювань анімації.
- Приватне `engineState` зберігає поточний контекст навчальних інструментів; це не браузерна глобальна змінна.
- React керує всіма оболонками, формами, проєкторами та їхнім життєвим циклом.
- Власний код застосунку — strict TypeScript зі звичайними ES-імпортами. Сторонній QR-генератор збережено у вихідному JavaScript із декларацією типів і ліцензією.
- `LegacyHtml` допускає текст уроків і графіку. Не створюй через нього новий інтерактивний UI.

### Адреси

| адреса | сторінка |
|---|---|
| `#/` | каталог курсів |
| `#/courses/math` | математика, групи уроків за класами |
| `#/courses/math/t1` | урок із завданнями |
| `#/courses/math/t1/k1` | завдання в зошиті |
| `#/courses/algebra` | алгебра |
| `#/courses/geometry` | геометрія |
| `#/courses/info/tools` | клавіатура та Windows |
| `#/courses/literacy` | медіаграмотність |
| `#/courses/html-css` | веброзробка |
| `#/tool/add?c=<JSON>` | вільна умова |
| `#/robo/robot/r5/mod1-3` | документ і якір |
| `#/3a/info/kb3/caps` | проєктор і пресет |

Старі адреси з класами відкривають відповідні курси й уроки; об’єднані теми мають явні `aliases`.

Адреси будуй функціями `src/navigation/routes.ts`. Для переходів використовуй `<a href>`.
Крок у URL не записується. Власна умова замінює URL без додаткового запису історії.
Невідомий маршрут повертає на найближчий відомий рівень. Старі `#rules` і `#mod1-3` канонізуються.
Зміна лише якоря або пресета документа не демонтує його React-компоненти.

### Матеріали-документи

Розділ містить `title`, `html` та необов'язкове `app`.
Текст і статичні SVG — довірені навчальні матеріали, які не треба переписувати на JSX.
`DocumentPage` керує змістом, фігурами, друком, редагованими полями та переходами до якорів.
`ContentSlot` монтує React-проєктор у виділене місце статті, зберігаючи посилання на конспекти.
Геометрія, клавіатура, Windows та панель кола мають власні модулі в папках відповідних курсів.
Для окремих матеріалів дозволено `init`/`onSub`/`leave` як межу спеціалізованого двигуна.
Кожен глобальний слухач або таймер має явне очищення при демонтуванні.

### Контракт математичних моделей

`src/runtime/tool.ts` надає `defineTool<Model>`, а `src/app/tools/register.ts` — `registerTools`. Перша функція створює визначення інструмента без реєстрації; друга перевіряє обов’язкові поля та унікальність усіх ID перед зміною каталогу. Підключення виконується один раз у `src/app/composition.ts`.

Визначення містить `build`, `read`, `view` і необов’язкові `prepare` та `animate`. Модель для `view`, `prepare` або `animate` має бути створена через `build` того самого визначення; довільний об’єкт із подібними полями не приймається. Контекст `view` та `animate` містить саме вибраний крок цієї моделі, його індекс, дані анімації й необов’язковий DOM-корінь. Дані анімації мають тип `unknown` і потребують перевірки перед читанням полів.

Спільна точна арифметика `Rational` зберігає чисельник і знаменник як `number`; локальна арифметика ірраціональних рівнянь використовує `BigInt`. AST формул, поліноми й обчислення залишаються в математичному ядрі, а рукописне письмо та сітка — у спільному зошиті. Навігацію й повідомлення надає `runtimeServices`.

Тести чистих алгоритмів можуть викликати їхні побудовники напряму. Перевірки через публічне визначення інструмента спочатку викликають його `build`; це зберігає перевірку належності моделі. Зафіксовані дані для перевірки сумісності знаходяться в `tests/fixtures/`.
