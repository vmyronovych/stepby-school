# Походження матеріалів курсу медіаграмотності

Курс StepBy School адаптує теми й педагогічні підходи освітньої ініціативи «#КодПравди». Це не офіційне видання ініціативи; погодження адаптації її авторами не заявляється.

## Методичні джерела

- Методичні рекомендації для вчителів початкових класів щодо проведення уроків у межах Місяця розвитку культури критичного мислення через медіаграмотність #КодПравди. Львів, 2026.
- «Фейки» — презентація з матеріалів «#КодПравди».
- «Чи варто це публікувати?» — презентація з матеріалів «#КодПравди».
- «Цифрова безпека» — презентація з матеріалів «#КодПравди».

## Що містить інтеграція

| Частина | Походження |
| --- | --- |
| Чотири теми, методичні орієнтири й навчальні навички | Адаптація матеріалів «#КодПравди»; не заявляємо їх як нову власну методику. |
| Діалоги, пояснення, наслідки, учнівські завдання, урок про Robux | Тексти, розроблені й відредаговані для StepBy School з опорою на методичні джерела. Практика відрізняється від демонстрацій. |
| Відомості Roblox, UNICEF, eSafety, FTC | Посилання й призначення джерел наведено в `practice-content.ts` та матеріалах учителя. Діалоги — вигадані адаптації, а не дослівні свідчення реальних людей. |
| Шість растрових ілюстрацій | Створені для StepBy School інструментом image_gen. Промпти збережено в `assets/media-literacy/`; зображення з презентацій організаторів не копіювалися. |
| Знімок вежі на столі (`tower-on-desk.png`) | Вигадана навчальна ілюстрація, створена вбудованим image_gen; ім’я, школа й номер на зошиті вигадані. Промпт: `assets/media-literacy/tower-on-desk-prompt.txt`. |
| Діалог Данила й мами (`danylo-mum-1.png`, `danylo-mum-2.png`) | Два кадри, створені вбудованим image_gen у стилі обкладинок курсу. Репліки залишені HTML-текстом. Промпти: `assets/media-literacy/danylo-mum-prompts.txt`. |
| Решта живих діалогів (`comic-*.png`) і фото з майстерні (`workshop-photo.png`) | Дев’ять пар ілюстрацій для десяти діалогів та окремий навчальний знімок створені вбудованим image_gen у спільному мальованому стилі. Одна пара Марка й мами використана у двох сценах звернення по допомогу. Репліки — доступний HTML-текст; деталі на посилці вигадані. Перелік файлів і промпти: `assets/media-literacy/dialogue-style-prompts.json`. |
| Комікси, навчальні чати й інтерактивні компоненти | Реалізація StepBy School. Інтерфейс чату стилізовано під месенджер; він не є справжнім листуванням чи інтеграцією з Viber. |
| QR-код | Kazuhiko Arase / qrcode-terminal. Ліцензії збережено в `vendor/QRCode/LICENSE` і `assets/media-literacy/qr-LICENSE.txt`. |

Оригінальні PDF, презентації, їхні обкладинки та сторонні відео не входять у цю інтеграцію.
