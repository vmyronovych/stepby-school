# Веброзробка

`index.ts` експортує готовий курс `webDevelopment`: його опис `subject` і повний перелік `topics`. Збирай усі записи каталогу всередині `course.ts`; реєстр застосунку задає лише порядок курсів.

Прочитай [спільні правила](../../../CLAUDE.md). Для українських текстів застосовуй [ukrainian-language](../../../.agents/skills/ukrainian-language/SKILL.md).

- `course.ts` задає порядок 27 занять; `lessons/<урок>/metadata.ts` містить метадані картки, `content.ts` — пояснення, `tasks.ts` — завдання та початкові файли, `assets/` — унікальні зразки результату.
- `shared/content/` містить типи, підготовку HTML, перевірку попереднього перегляду та бібліотеки навчальних медіа. `shared/ui/` отримує завдання й початковий код через параметри; не імпортуй сюди конкретні заняття.
- `ui/lessons.ts` поєднує практику та налаштування занять. `documents/index.ts` збирає документи. Публічні входи: `index.ts` для каталогу, `ui/index.ts` для практики, `documents/index.ts` для документів.
- `ui/documents.tsx` вставляє практику у відповідний документ через `webDocumentContent`, доступний у `ui/index.ts`. Застосунок не визначає місце вставлення редактора.
- Заняття не імпортують одне одного або інші курси. Зберігай ідентифікатори, старі адреси, порядок завдань і стан роботи під час перемикання.
- Учнівський HTML відкривається лише в ізольованому попередньому перегляді. Не послаблюй обмеження скриптів, мережевих адрес, форм та вкладених документів. `LegacyHtml` не призначений для учнівського коду.
- Канонічні ресурси належать курсу. `publication.cjs` зберігає адреси `assets/web-development/*` і `css/web-development.css`, включно із завантаженнями та офлайн-медіа.
- Генератори знаходяться в `scripts/`: `generate-web-media.cjs` створює SVG та ZIP, `generate-web-av.cjs` — аудіо й відео, `generate-web-targets.cjs` — зразки результатів. Запускай із кореня репозиторію. Необов’язковий перший аргумент — окрема папка результатів для перевірки; без аргументу оновлюються джерела курсу. Після зміни генератора перевір його реальний запуск.
- Курсові тести знаходяться в `tests/`, браузерні — у `tests/browser/`; вони автоматично входять до загальних запусків. Виконай перевірки з кореневого `CLAUDE.md`, включно з усіма заняттями, завантаженнями, телефоном, `file://` і зменшеним рухом.

## Підготовка занять

- Аудиторія — підлітки без досвіду програмування. Пояснюй нові поняття перед вправами; теми та їхню послідовність узгоджуй із користувачем.
- Використовуй джерела для власних пояснень і прикладів. Не копіюй їх дослівно й не додавай бренди або посилання на сайт вихідних навчальних матеріалів.
- Перевіряй теорію, завдання та зразки разом. Застарілі HTML-теги й атрибути замінюй сучасними засобами; пояснюй зміст елементів, а не лише їхній вигляд.
- Показуй зв’язок коду з результатом через схеми, підсвічення, рамки й текстові підписи. Самого кольору недостатньо.
- Кожне завдання має умову, текст для роботи, підказку, список самоперевірки й зразок результату. Вибір завдання — окремі кнопки з видимим активним станом.
- Генеруй зразки з робочого HTML/CSS із заданим розміром вікна; допускай відмінності доступних шрифтів.
- Для локальної роботи пояснюй завантаження й відкриття HTML, CSS та медіафайлів, розміщення файлів і відносні шляхи.
- Другий міні-проєкт має футбольну тему; команди, емблеми й результати — власні та вигадані.
