# Медіаграмотність

`index.ts` експортує готовий курс `mediaLiteracy`: його опис `subject` і повний перелік `topics`. Збирай усі записи каталогу всередині `course.ts`; реєстр застосунку задає лише порядок курсів.

Прочитай [спільні правила](../../../CLAUDE.md) та [правила підготовки матеріалів](docs/guidelines.md). Для українських текстів застосовуй [ukrainian-language](../../../.agents/skills/ukrainian-language/SKILL.md).

## Де працювати

| Зміна | Файли |
|---|---|
| Назва й опис картки | `lessons/<тема>/metadata.ts` |
| Навчальний зміст, історії, практика, наслідки й ключі вчителя | `lessons/<тема>/` |
| Окремий урок про Robux та його конспект | `lessons/robux/` |
| Показ діалогів, практика, QR-коди й шаблон конспекту | `shared/ui/` |
| Типи, підготовка даних, перевірка відповідей і спільні джерела | `shared/content/` |
| Компонування уроків і режимів | `ui/` |
| Стилі й матеріали кількох уроків | `shared/styles/`, `shared/assets/` |
| Походження матеріалів | [docs/sources.md](docs/sources.md) |

Публічні входи: `index.ts` — каталог і розпізнавання режиму уроку; `ui/index.ts` — екран та навчальний зміст для композиції застосунку. Каталог у `course.ts` читає лише метадані. Спільні компоненти отримують дані через параметри; вони не імпортують конкретні заняття. Заняття не імпортують одне одного.

`ui/page.tsx` визначає екран, навігаційний ланцюжок і видимість шапки для режимів уроку. Функція `mediaPage` доступна через `ui/index.ts`; правила окремої учнівської сторінки не дублюються в `app`.

Курс має чотири теми та окремий урок про Robux, доступний із теми цифрової безпеки. Зберігай ідентифікатори, прямі посилання, режими «Разом у класі», «Практика учня», матеріали вчителя й окрему учнівську сторінку. Учнівська сторінка не повинна містити конспект і ключі вчителя.

`publication.cjs` публікує зображення, промпти й ліцензії в `dist/assets/media-literacy/`, стилі — у `dist/css/media-literacy.css`. Публічні адреси ресурсів збережено для офлайн-роботи. Нові унікальні матеріали розміщуй біля відповідного заняття; матеріали кількох занять — у `shared/assets/`. Зберігай сторонню ліцензію QR-генератора.

Виконай перевірки з кореневого `CLAUDE.md`. Курсові тести знаходяться в `tests/`, браузерні — у `tests/browser/` і автоматично входять до загальних запусків. Перевір усі чотири теми й Robux, режими уроку, історію переходів, телефон та `file://`.

Посилання отримуй від застосунку через `CourseLinks` у параметрах функцій або через `useCourseLinks` усередині React-компонента. Не імпортуй `app/navigation`; курс визначає місце переходу, застосунок формує адресу.
