# Інформатика

`index.ts` експортує готовий курс `informatics`: його опис `subject` і повний перелік `topics`. Збирай усі записи каталогу всередині `course.ts`; реєстр застосунку задає лише порядок курсів.

Прочитай [спільні правила](../../../CLAUDE.md) та [правила навчальних матеріалів](docs/materials.md). Для українських текстів застосовуй [ukrainian-language](../../../.agents/skills/ukrainian-language/SKILL.md).

- `course.ts` — каталог матеріалів та інструментів; `index.ts` — його публічний вхід. `grades` задає групи класів; `cls` зберігає чинні адреси й не використовується для групування.
- `ui/index.ts` експортує `informaticsDocumentNavigation`: навігаційний ланцюжок і вкладки для документа. Належність до розділу «Інструменти» визначає курс за `topic.kind`.
- `ui/documents.tsx` підключає клавіатуру й Windows до документів через `informaticsDocumentContent`, доступний у `ui/index.ts`. Тут також визначається перехід під час вибору пресета.
- `lessons/grade-3/` і `lessons/grade-4/` — КТП та конспекти відповідного класу. Зберігай порядок, ідентифікатори й затверджені формулювання тем.
- `documents/` збирає навчальні документи й файл для НІТ. Публічний вхід — `documents/index.ts`. Каталог і `InfoDocumentServices` (посилання та повідомлення) передаються в `composeInfoDocuments` через параметри. Проєктори приймають `onPresetChange`; їхні контролери не змінюють адресу сторінки.
- `tools/keyboard/` та `tools/windows/` містять реалізацію, типи й стилі інструментів. Зовнішній код імпортує тільки їхні `index.ts`.
- `shared/` містить матеріали й оформлення кількох частин курсу. Спільний код не імпортує конкретні заняття.
- `publication.cjs` зберігає чинні публічні адреси стилів. Зміни інструментів перевіряй із пресетами, переходами «Назад» / «Вперед», збереженням стану та очищенням слухачів.
- Курсові тести знаходяться в `tests/`, браузерні — у `tests/browser/`; вони автоматично входять до загальних запусків. Виконай усі перевірки з кореневого `CLAUDE.md`, зокрема для телефона й `file://`.
