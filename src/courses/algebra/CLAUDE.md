# Алгебра

`index.ts` експортує готовий курс `algebra`: його опис `subject` і повний перелік `topics`. Збирай усі записи каталогу всередині `course.ts`; реєстр застосунку задає лише порядок курсів.

Прочитай [спільні правила](../../../CLAUDE.md), [правила зошита](../../components/notebook/CLAUDE.md) та [математичного ядра](../../lib/math/CLAUDE.md). Для українських текстів застосовуй [ukrainian-language](../../../.agents/skills/ukrainian-language/SKILL.md).

- `course.ts` визначає навчальну послідовність; `lessons/<назва>/lesson.ts` — єдине джерело метаданих і задач уроку. Поле `grades` визначає групи класів. Один урок може відображатися в кількох групах.
- Ідентифікатори уроків і завдань зберігай. Попередні адреси перенесених або об’єднаних уроків записуй у `aliases`.
- Унікальна логіка, матеріали й стилі живуть біля уроку; спільне для кількох уроків — у `shared/`. Не імпортуй сусідні уроки або інші курси.
- Публічний каталог — `index.ts`, виконання й підключення моделей — `runtime/index.ts`, поля вводу — `ui/index.ts`. Налаштування адрес — окремий публічний файл `routing.ts`, який містить лише дані та імпорти типів. Застосунок підключає лише ці входи.
- Зошит підключай через `components/notebook`. Навчальний алгоритм визначає кроки та пояснення, спільний зошит їх показує. Власні поля вводу зберігай біля уроку або у `shared/`; `ui/index.ts` експортує повний перелік `algebraInputs`, який підключає `app/tools/`. Початкові значення, приклади й показ формул належать курсу.
- Окремого розділу інструментів немає. Готові завдання та введення власних умов доступні в уроках. Не додавай заглушок матеріалів.
- Стилі публікує `publication.cjs`; навчальні приклади й текст не дублюй у Markdown.
- Виконай загальні перевірки з кореневого `CLAUDE.md`, включно з прямими посиланнями, телефоном, `file://` і зменшеним рухом.

## Навчальні пояснення

- Назви прикладів мають описувати дію або тип задачі. Не повертай номери вправ із підручника в картки, списки вибору чи умови.
- Розділяй теорію заголовками; формули прикладів показуй окремими рядками через спільний рендер.
- В ірраціональних рівняннях після усунення кореня розв’язуй лінійне рівняння без зайвого зведення до нуля, ділення на 1 або зведення одного доданка. Перевіряй доцільність кожного кроку.
- Для тригонометричних виразів відділяй назву функції від аргументу математичним проміжком; перевіряй дроби й квадрат функції в теорії та зошиті.

## Можливості ірраціональних рівнянь

Урок відкривається за `#/courses/algebra/irrational`; стара адреса `#/10a/math/irrational` збережена. Під коренем підтримуються многочлени до другого степеня. Для квадратного кореня справа може бути лінійний вираз або квадратний корінь; для кубічного — число або кубічний корінь після перенесення доданків. Рівняння третього степеня після піднесення та змішані показники коренів не підтримуються.

Кубічний корінь вводиться як `root(3, x - 1)`, `cbrt(x - 1)` або `∛(x - 1)`. Метод «Заміна t = √x», наприклад для `x - 3sqrt(x) + 2 = 0`, розв’язує квадратне рівняння відносно t, відкидає t < 0 й повертається до x = t².

Тест реалізації: `node --test src/courses/algebra/tests/irrational.test.cjs` із кореня репозиторію.
