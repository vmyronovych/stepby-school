# Зображення з Mcar

Вхід: файл `.mcar`, доступ до редактора Mcar та місце збереження результату. Вихід: зображення потрібної схеми або програми, відтворене самим Mcar.

## Скрипти скіла

- [capture.mjs](scripts/capture.mjs) — команда для довільного `.mcar`; запускає Mcar, імпортує проєкт і зберігає зображення.
- [capture-wiring.mjs](scripts/capture-wiring.mjs) — отримує PNG схеми, перевіряє проводи й підписи.
- [capture-blocks.mjs](scripts/capture-blocks.mjs) — отримує PNG або автономні SVG програми та відкриває визначення власних блоків.

Потрібні залежності репозиторію, Chromium Playwright і локальний Mcar із залежностями та зібраним `web/dist`. Шлях до Mcar передавай явно. Приклад запуску з папки цього скіла:

```sh
node scripts/capture.mjs --mcar /path/to/mcar --input /path/to/project.mcar --kind wiring --output /path/to/wiring.png
node scripts/capture.mjs --mcar /path/to/mcar --input /path/to/project.mcar --kind blocks --output /path/to/program.svg
```

Для PNG блоків задай вихідний файл із розширенням `.png`. Для визначення власного блока додай `--definition` з його ідентифікатором. Якщо програма містить кілька окремих ланцюжків, SVG зберігаються окремими файлами з суфіксами `-1`, `-2` тощо; PNG охоплює їх разом. Команда повертає шляхи джерела та створених зображень.

Для пакетної обробки імпортуй `createCaptureSession` із `capture.mjs` і закривай сеанс у `finally`. Вибір проєктів та облік зображень залишай коду, який викликає скіл. Спільна [перевірка перетинів](../../../scripts/wire-clearance.mjs) використовується також генераторами й тестами, тому зберігається поза скілом.

## Відкрити проєкт

1. Використай доступний редактор Mcar або запусти його з наявної локальної копії за її інструкціями. Не припускай фіксованої адреси чи розташування репозиторію.
2. Імпортуй `.mcar` штатною командою відкриття проєкту. Перевір назву, завантажені компоненти й блоки; переконайся, що імпорт завершився без помилок.
3. Дочекайся завантаження шрифтів, зображень компонентів і завершення автоматичного розведення проводів. В автоматизації перевіряй готовність цих елементів, а не покладайся на фіксовану затримку.

## Підготувати потрібний вигляд

**Монтажна схема.** Відкрий редактор підключень і впиши схему в область перегляду. Приховай палітру та службові панелі. Залиш видимими назви компонентів і використаних контактів. Перевір кінці проводів, накладання, перетини та підписи; не приховуй проблемні ділянки обрізанням зображення.

**Блокова програма.** Впиши програму в область перегляду. Захопи всі потрібні ланцюжки блоків. Визначення власних блоків відкрий у їхньому редакторі й збережи окремо, якщо вони потрібні для пояснення. Довгу програму розділи на читабельні фрагменти зі зрозумілим порядком.

## Зберегти й перевірити

- Отримай PNG потрібної області або збережи SVG з редактора. Для автономного SVG збережи стилі, визначення й розміри; він має правильно відкриватися поза Mcar.
- Не змінюй логіку програми чи електричні з’єднання заради знімка. Якщо потрібне виправлення вихідного проєкту, назви його окремо.
- Відкрий готовий файл у цільовому розмірі. Перевір читабельність, відсутність обрізаних деталей і відповідність проєкту. Не замінюй відтворені Mcar схеми або блоки намальованою імітацією.
- Збережи файли в заданому місці. У результаті вкажи вихідний `.mcar` і отримані зображення. Якщо проєкт веде облік джерел зображень, онови його за місцевими правилами.
