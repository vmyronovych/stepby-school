# Зображення схем і блоків із Mcar

Вхід — готовий проєкт `.mcar` у `lessons/lesson-NN/files/`. Результат — зображення для заняття та запис про файл, із якого його отримано.

Скрипти відкривають проєкт у Mcar й отримують зображення його схеми та блоків.

## Перед знімком

- Визнач заняття, потрібний проєкт і матеріал: монтажна схема чи блоки програми.
- Переконайся, що `.mcar` містить потрібні зміни. Знімок не змінює програму або підключення.
- Звір схему з [правилами курсу](../../../CLAUDE.md#схеми). Для чотирьох моторів і QTR врахуй [відомі обмеження](../../../docs/course.md#обмеження-матеріалів).

Команди виконуй із кореня репозиторію. Потрібні залежності цього проєкту й сусіднього `../mcar`, зібраний `../mcar/web/dist` та Chromium Playwright. Якщо чогось бракує, назви потрібну підготовку.

## Отримання зображень

| Матеріал | Команда |
|---|---|
| Блоки заняття 7 | `node src/courses/robotics/scripts/render-course.mjs --lessons=7` |
| Схема одного мотора й блоки заняття 8 | `node src/courses/robotics/scripts/render-mcar.mjs ../mcar` |

У першій команді заміни `7` потрібним номером або переліком через кому. Вона знімає блоки вибраних занять; монтажні схеми додатково знімаються лише для занять 6 і 11. Схему одного мотора, спільну для кількох занять, оновлює друга команда. Не запускай знімання всього курсу заради одного заняття.

Скрипти зберігають зображення в `lessons/lesson-NN/assets/` або `shared/assets/`. Записи про джерела оновлюються в `shared/content/captures.json` та `resources.ts`; для заняття 8 — у `lessons/lesson-08/captures.json`. Не виправляй контрольні суми вручну.

## Перевірка результату

1. Переглянь diff: потрібні зображення, записи про джерела та відсутність сторонніх змін.
2. Виконай `npm run build`. Перевір проєкти командою `node src/courses/robotics/scripts/check-course.mjs ../mcar`; для заняття 8 використай `node src/courses/robotics/scripts/check.mjs ../mcar`.
3. Відкрий змінений матеріал у занятті на комп’ютері й телефоні. Перевір читабельність блоків і підписів, контакти та відсутність перетинів проводів. Сам успішний запуск скрипту цього не доводить.

Якщо наявний скрипт не знімає потрібну схему, доповни його або отримай знімок у Mcar. Збережи зв’язок зображення з вихідним `.mcar`.
