# Інтерактивне коло в занятті

Використовуй [embed.mjs](scripts/embed.mjs), щоб підключити готовий дослід без ручного редагування імпортів і структури заняття.

## Вхідні дані

- Файл даних заняття `lesson.ts` з `export const content = { ... }`. Поля `classroomMaterials` і `slides` мають бути явними масивами об’єктів. Скрипт не обробляє дані, зібрані через функції чи spread.
- Файл схеми в папці цього заняття з іменованим експортом об’єкта типу `CircuitPreset`, наприклад `export const circuitPreset: CircuitPreset = { ... }`. Створюй коло функціями `cbNewBoard`, `cbAddPart` і `cbAddWire` через [публічний інтерфейс інструмента](../../../tools/circuit/index.ts).
- JSON пояснення з текстовими полями `title`, `prompt`, `text`, `question`, `answer`. Для додаткового запитання можна додати `followup: { question, answer }`.

Пояснення має визначати дію дитини, очікуване спостереження та запитання. Скрипт підключає матеріал; правильність кола й пояснення перевір самостійно.

## Обмеження моделі

- Анімація показує рух електронів. Струми обчислюються за з’єднаннями.
- Мотор — навантаження 24 Ом без інерції, самоіндукції та зворотної ЕРС.
- NPN — спрощений ключ, а не модель підсилювача чи конкретної деталі. Струм бази керує шляхом колектор–емітер; струм емітера дорівнює сумі струмів бази й колектора. Контакти позначені B/C/E, стрілка емітера спрямована назовні.
- Параметри NPN: база–емітер — 0,7 В і 10 Ом; увімкнений колектор–емітер — 0,2 В і 1 Ом; поріг увімкнення — 1 мА струму бази. Реалізація — [power-parts.ts](../../../tools/circuit/engine/power-parts.ts). Нагрівання мотора й транзистора не моделюється.
- Вигляд «Макетка» підтримує двоконтактні деталі й одне джерело. Для транзистора або кількох джерел використовуй вигляд «Схема».
- Скасування відновлює схему, але не заряд і пошкодження деталей. Навчальна модель не замінює монтажну схему для фізичного складання.

## Запуск

З папки цього скіла виконай:

```sh
node scripts/embed.mjs --lesson /path/to/lesson.ts --preset /path/to/experiment.ts --export circuitPreset --discussion /path/to/discussion.json
```

Заміни шляхи й назву експорту своїми. Потрібні встановлені залежності репозиторію. Додай `--dry-run`, щоб переглянути підготовлений файл без запису.

Скрипт додає імпорт схеми, поле `experiment`, матеріал «Дослід» та пояснення. Загальний екран підхоплює дослід із даних заняття. Повторний запуск оновлює пояснення без дублікатів. Інший уже підключений дослід скрипт не замінює; вихідну схему та інші заняття не редагує.

Експортуй готовий об’єкт `CircuitPreset`; не створюй його заново під час кожного відображення. Зміна об’єкта повторно монтує сеанс. Спільний компонент зберігає окремий стан кожного досліду, призупиняє прихований дослід і звільняє ресурси під час демонтування.

## Перевірка

Переглянь зміни та виконай `npm run typecheck` з кореня репозиторію. Відкрий дослід у занятті: перевір початковий стан, запропоновані дії та скидання. Звір пояснення з поведінкою моделі.

Перевір відображення на комп’ютері й телефоні. Перемикання матеріалів має зберігати стан, а приховування — призупиняти звук та анімацію.
