# Математика

`index.ts` експортує готовий курс `mathematics`: його опис `subject` і повний перелік `topics`. Збирай усі записи каталогу всередині `course.ts`; реєстр застосунку задає лише порядок курсів.

Прочитай [спільні правила](../../../CLAUDE.md), [правила зошита](../../components/notebook/CLAUDE.md) та [математичного ядра](../../lib/math/CLAUDE.md). Для українських текстів застосовуй [ukrainian-language](../../../.agents/skills/ukrainian-language/SKILL.md).

- `course.ts` визначає навчальну послідовність; `lessons/<назва>/lesson.ts` — єдине джерело метаданих і задач уроку. Поле `grades` визначає групи класів. Один урок може відображатися в кількох групах.
- Ідентифікатори уроків і завдань зберігай. Попередні адреси перенесених або об’єднаних уроків записуй у `aliases`.
- Унікальна логіка, матеріали й стилі живуть біля уроку; спільне для кількох уроків — у `shared/`. Не імпортуй сусідні уроки або інші курси.
- Публічний каталог — `index.ts`, виконання й підключення моделей — `runtime/index.ts`, поля вводу — `ui/index.tsx`. Налаштування адрес — окремий публічний файл `routing.ts`, який містить лише дані та імпорти типів. Застосунок підключає лише ці входи.
- Зошит підключай через `components/notebook`. Навчальний алгоритм визначає кроки та пояснення, спільний зошит їх показує. Власні поля вводу зберігай біля уроку або у `shared/`; `ui/index.tsx` експортує повний перелік `mathematicsInputs`, який підключає `app/tools/`.
- Окремого розділу інструментів немає. Готові завдання та введення власних умов доступні в уроках. Не додавай заглушок матеріалів.
- Стилі публікує `publication.cjs`; навчальні приклади й текст не дублюй у Markdown.
- Виконай загальні перевірки з кореневого `CLAUDE.md`, включно з прямими посиланнями, телефоном, `file://` і зменшеним рухом.
