# Спільні компоненти

Прочитай [правила репозиторію](../../CLAUDE.md). Українські тексти перевіряй за [ukrainian-language](../../.agents/skills/ukrainian-language/SKILL.md).

Кожен компонент — окрема папка з одним власником реалізації, типів, стилів, ресурсів і тестів. Створюй лише потрібні файли. `button` містить кнопку та посилання-кнопку зі спільним оформленням.

Зовнішній код імпортує модуль через його `index.ts` або `index.tsx`. Внутрішні файли не є публічними. Виняток: задокументовані входи `notebook/handwriting` і `notebook/grid`, а також `notebook/inputs` для математичного ядра. Компоненти не імпортують курси, каталог чи `app`; потрібні дані та дії отримують через параметри.

Токени, скидання браузерних стилів і загальний каркас сторінки залишаються в `css/base.css`. Власні стилі компонента живуть у його папці. `publication.cjs` публікує лише явний перелік CSS, без інструкцій і тестів.

Для зошита обов’язково прочитай [локальні правила](notebook/CLAUDE.md). `legacy-html` приймає лише довірену розмітку репозиторію; користувацький HTML там заборонено.
