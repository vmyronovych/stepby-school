# Спільні компоненти

Прочитай [правила репозиторію](../../CLAUDE.md). Українські тексти перевіряй за [ukrainian-language](../../.agents/skills/ukrainian-language/SKILL.md).

Кожен компонент — окрема папка з одним власником реалізації, типів, стилів, ресурсів і тестів. Створюй лише потрібні файли. `button` містить кнопку та посилання-кнопку зі спільним оформленням.

Зовнішній код імпортує модуль через його `index.ts` або `index.tsx`. Внутрішні файли не є публічними. Виняток: задокументовані входи `notebook/handwriting` і `notebook/grid`, `notebook/inputs` для полів введення та `notebook/rendering` для показу математичних записів. Компоненти не імпортують курси, каталог чи `app`; потрібні дані та дії отримують через параметри.

Токени, скидання браузерних стилів і загальний каркас сторінки залишаються в `css/base.css`. Власні стилі компонента живуть у його папці. `publication.cjs` публікує лише явний перелік CSS, без інструкцій і тестів.

Для зошита обов’язково прочитай [локальні правила](notebook/CLAUDE.md). `legacy-html` приймає лише довірену розмітку репозиторію; користувацький HTML там заборонено.

`document/` — спільний переглядач навчальних документів, зміст, ілюстрації, друк і стан редагованих полів. Реєстрація документів належить `app/documents/registry.ts`; навчальний зміст та дії конкретного курсу передаються ззовні. Тип `DocumentNavigation` описує передані навігаційні посилання й необов’язкові вкладки; правила їх побудови належать курсам. Тип `DocumentContentRenderer` описує функцію, якою курс створює інтерактивний вміст документа; вибір інструмента й місця його вставлення належить курсу. Не додавай сюди КТП, конспекти, перелік курсів або курсові команди.

`file-export/` — спільне створення ZIP та одноколонкового XLSX без мережі. Назви аркушів, заголовки й дані конкретного експорту визначає його курс.

`legacy-html` також надає `esc` для екранування довірених значень у HTML. `motion` читає браузерне налаштування зменшеного руху. Ці функції не належать математичним обчисленням.
