# Визначення навчального інструмента

Прочитай [правила репозиторію](../../../CLAUDE.md).

`index.ts` надає `defineTool`, тип визначення та контекст кроку. Він перевіряє, що модель створено цим інструментом, а вибраний крок належить цій моделі.

Модуль не реєструє інструменти, не зберігає стан застосунку й не імпортує курси, компоненти або `app`. Реєстрація належить `app/tools/register.ts`; алгоритми та тексти — відповідному курсу.
