# StepBy School

Освітній портал українською: шкільні предмети й гуртки **крок за кроком**. Для учня — інтерактивні інструменти, що показують розв'язання так, ніби його пишуть від руки на зошиті в клітинку. Для вчителя — КТП, конспекти уроків і схеми на проєктор.

**▶ Відкрити портал: [vmyronovych.github.io/stepby-school](https://vmyronovych.github.io/stepby-school/)**

![Додавання дробів 7/10 + 2/15 крок за кроком — один з інструментів порталу](docs/fractions.gif)

## Що всередині

Зараз на порталі такі предмети й гуртки (інші в розробці):

- **Математика 5–6 і 10 класів** — додавання, віднімання, множення й ділення в стовпчик, дільники і кратні, розкладання на прості множники, НСД і НСК, дії з дробами, рівняння, пропорції, область визначення функції, ірраціональні рівняння. Кожен інструмент приймає власну умову.
- **Інформатика 3–4 класів (НУШ)** — КТП на 2026/2027, конспекти уроків для вчителя, файл для НІТ і схеми на проєктор: клавіатура та навчальна копія Windows 10/11.
- **Гурток робототехніки (3–4 кл.)** — поурочні плани і конструктор електричного кола зі схемою та макеткою.

## Запуск

Для перегляду відкрийте `index.html` у браузері. Працюють `file://`, GitHub Pages і офлайн-режим.
Локальний React-бандл уже є в `assets/`. CDN і бекенд не потрібні.

Для розробки потрібен Node.js 22 або новіший:

```sh
npm ci
npm run dev
```

Відкрийте `http://127.0.0.1:5173`. Зміни в `src/` автоматично перебудовуються; оновіть сторінку після зміни.

```sh
npm run build          # strict TypeScript + production-бандл
npm test               # математичні перевірки та маршрути
npx playwright install chromium
npm run test:browser   # перевірки UI у Chromium
```

Після змін React-коду додайте до коміту оновлені `assets/app.js` та `assets/app.js.LEGAL.txt`.
Якщо змінено ресурси з параметром `?v=`, оновіть їхню версію в `index.html`.

## React і TypeScript

Потік учня та спільна оболонка інструментів тепер використовують React і strict TypeScript.
Спільні компоненти: кнопки, картки, навігація, заголовки та зошит.

- `src/components/` — спільні компоненти; `Notebook` підтримує React-вміст і наявні формули.
- `src/features/student/` — потік учня: `StudentPage` вибирає екран, `screens/` складає сторінки, `components/` містить картки й секції.
- `src/features/tools/` — оболонка інструмента: `ToolPage`, панелі та кнопки кроків у `components/`, анімація в `hooks/`.
- Компоненти функцій отримують типізовані props; глобальний стан читають лише точки входу `StudentPage` та `ToolPage`.
- `src/types.ts` — типи даних і контракт межі зі старими інструментами.
- `src/legacy.d.ts` — тимчасові типи глобальних API.
- `src/main.tsx` — синхронний міст між роутером і React; перед документами React демонтується.
- `scripts/build.mjs` — esbuild; створює звичайний скрипт із локальними залежностями.

Міграція поступова. Математичні ядра, анімації, дані, роутер і документи поки залишаються в `js/`.
Їхні HTML-шаблони проходять через `LegacyHtml`. Передавайте туди лише довірену розмітку з наявним екрануванням введення.
Новий UI пишіть компонентами в `src/`. Не змінюйте `assets/` вручну.

Наступні етапи: типізувати дані й реєстр; переносити введення та відображення кожного інструмента;
потім перенести роутер і документи. Перевіряйте кожен інструмент до видалення його глобального API.

Як усе влаштовано, вимоги до анімації й перевірка змін — у [CLAUDE.md](CLAUDE.md).

## Перевірка ірраціональних рівнянь

Математичні перевірки без додаткових залежностей:

```sh
node --test tests/irrational.test.cjs
```

Урок: `#/10a/math/irrational`. Під коренем підтримуються многочлени до x².
Для квадратного кореня справа може бути лінійний вираз або квадратний корінь.
Для кубічного — число або кубічний корінь після перенесення доданків.
Введення кубічного кореня: `root(3, x - 1)`, `cbrt(x - 1)` або `∛(x - 1)`.
Рівняння третього степеня після піднесення та змішані показники коренів поки не підтримуються.

Для методу заміни виберіть «Заміна t = √x». Приклад: `x - 3sqrt(x) + 2 = 0`.
Інструмент розв’язує квадратне рівняння відносно t, відкидає t < 0 та повертається до x = t².
