# StepBy School

Освітній портал українською зі шкільними курсами, покроковими розв’язаннями в зошиті, інтерактивними дослідами та матеріалами для вчителя. Працює через браузер і з локальної офлайн-копії.

**[Відкрити портал](https://vmyronovych.github.io/stepby-school/)**

## Курси

Головна сторінка показує курси. У математичних курсах та інформатиці матеріали згруповані за класами; порожніх предметів у каталозі немає.

| Курс | Що доступно |
|---|---|
| Математика, 5–6 класи | Обчислення в стовпчик, дільники й кратні, прості множники, НСД і НСК, дроби, рівняння та пропорції |
| Алгебра, 10 клас | Область визначення, ірраціональні рівняння, раціональні показники степеня, радіанна міра й тригонометричні вирази |
| Геометрія, 9 клас | Вектори, множення вектора на число та скалярний добуток: досліди й покрокові задачі |
| Інформатика, 3–4 класи | КТП на 2026/2027, конспекти, експорт для НІТ; клавіатура й навчальна копія Windows у розділі «Інструменти» |
| Робототехніка, 3–4 класи | 32 заняття: показ, практика в парі, матеріали вчителя й окрема учнівська сторінка; електричне коло, Морзе та 73 файли Mcar |
| Медіаграмотність, 1–4 класи | Чотири теми та урок про Robux: показ у класі, 21 ситуація для практики й матеріали вчителя |
| Веброзробка для підлітків | 27 занять, 80 практичних завдань, включно з чотирма міні-проєктами; редактор HTML/CSS, зразки та завантаження навчальних медіа |

У математичних уроках готові задачі й введення власних умов доступні відповідно до можливостей уроку. Навчальний стан зберігається в пам’яті вкладки. У веброзробці роботу можна завантажити у файли й відкрити знову.

## Локальний запуск

Потрібен Node.js 22 або новіший та npm:

```sh
npm ci
npm run dev
```

Відкрийте `http://127.0.0.1:5173`. Сервер показує `dist/` і перебудовує код та ресурси після змін; оновлюйте вкладку вручну. Після зміни скриптів збірки або переліку підключених маніфестів публікації перезапустіть сервер. Інший порт: `STEPBY_PORT=5174 npm run dev`.

Для офлайн-копії:

```sh
npm run build
```

Відкрийте `dist/index.html` у браузері. Переносьте **всю папку `dist/`**: для її перегляду не потрібні Node.js, репозиторій чи інтернет. Кореневий `index.html` — шаблон для збірки.

`npm run preview` показує вже зібраний сайт через локальний HTTP без перебудови.

## Перевірки

```sh
npm run format:check
npm test
npx playwright install chromium
npm run test:browser
```

`npm test` перевіряє типи, збирає сайт і запускає модульні та архітектурні тести. Браузерний набір також починається зі збірки та перевіряє HTTP, `file://`, навігацію, інструменти й мобільні екрани. Окремо доступні `npm run check:architecture` та `npm run test:robotics`.

Для окремого курсу після `npm run build` виконайте `node scripts/test.mjs <назва-папки-курсу>`, наприклад `node scripts/test.mjs algebra`. Форматуйте лише змінені TS/TSX-файли; команда `npm run format` форматує весь `src/`.

## Сумісність посилань

Адреса `#/media/literacy` продовжує відкривати медіаграмотність через `#/courses/literacy`. Прямі адреси уроків, зокрема `#/media/literacy/truth/student` і `#/media/literacy/safety/robux-student`, збережено. Учнівська сторінка містить лише практику; це спрощення навігації, а не контроль доступу.

Старі адреси математичних уроків із класами також підтримуються. Нові посилання будуйте функціями з `src/navigation/routes.ts`.
