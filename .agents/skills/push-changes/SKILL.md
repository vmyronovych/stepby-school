# Перед кожним push

Залишай зміни локально. Виконуй `git push` лише на окреме явне прохання користувача. Попередній дозвіл відкрити або оновити PR не означає дозволу пушити кожну наступну правку.

Перед кожним push у будь-яку віддалену гілку запусти локально й дочекайся успішного завершення всіх перевірок:

1. `npm run format:check`.
2. `npm test` — включає перевірку типів, збірку, модульні й архітектурні тести.
3. `npm run test:browser` — включає збірку та браузерні тести.
4. `git diff --check` і `git diff --cached --check`.

Перевіряй остаточні зміни, які підуть у push. Не покладайся на результати попереднього push або віддаленого CI. Якщо після перевірок змінилися файли, повтори перевірки перед push.

Якщо хоча б одна перевірка впала, не запустилася або не завершилася, не виконуй push. Не обходь помилку й не вимикай перевірку. Дай користувачу короткий підсумок за скілом [ukrainian-language](../ukrainian-language/SKILL.md): що не пройшло, відома причина або що ще треба з’ясувати, наступний крок. Явно зазнач: «Зміни не запушено».

Автоматичні перевірки й публікація запускаються лише після push у `main`. Вони не замінюють локальні перевірки перед push.
