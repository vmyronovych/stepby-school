# Word 2013 teaching illustrations and visual references

The lesson now uses **authored Ukrainian SVG illustrations** in `illustrations/`,
generated by `scripts/create-word2013-illustrations.mjs`. The user requested
drawn representations of Word 2013. These are simplified educational drawings,
not captures from a running application; every asset includes this label.
Their labels, fields, document text and outlines remain sharp at projector sizes.

The sample text matches `../info4-lesson8-about-me.docx`. The editor, title
selection, New, Save As, Open and file dialogs depict the lesson's own example.
Run `node scripts/create-word2013-illustrations.mjs` to regenerate all SVGs.

Layout references: the GCFGlobal course below; Ukrainian ribbon terminology
was cross-checked against the Ukrainian Word 2013 teaching material at
https://api.dspace.wunu.edu.ua/api/core/bitstreams/dd1c3355-e837-43e6-8764-6732e3a494f8/content
and Microsoft's Ukrainian Word help:
https://support.microsoft.com/uk-ua/word/basic-tasks-in-word
